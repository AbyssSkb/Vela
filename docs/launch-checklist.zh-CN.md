# Vela 发布验收清单

[English](launch-checklist.md)

每次发布按候选版本记录结果。为每条检查注明设备、系统、应用版本、网络、发送方向和实际结果。安装包测试和真机收发各自留存记录。 [发布流程](releasing.zh-CN.md)

## 检查候选版本

- [ ] 确认标签、提交和 `pubspec.yaml` 中的版本一致。
- [ ] 核对该提交的 CI、打包和安装启动检查。
- [ ] 确认发布版使用已有的 Android 签名和更新公钥，应用标识与数据目录能延续。
- [ ] 检查草稿中的各平台安装包、签名更新源、更新包和 SHA-256 校验文件。
- [ ] 安装和升级说明有对应的处理步骤。Android 调试包用户需要先备份收到的文件，再卸载并安装公开版。
- [ ] 检查公开内容中的示例文件、截图、日志和第三方许可证。

## 安装和使用

| 平台 | 安装后先测 |
| --- | --- |
| Android | 安装正式 ARM64 包。配对、系统分享、后台通知、接收后打开内容。 |
| macOS | 在 Apple 芯片和 Intel 设备上安装 DMG。检查菜单栏、钥匙串、系统分享、登录启动和系统提示。 |
| Windows | 用普通用户安装。第二次启动恢复原窗口，托盘还能打开和退出，卸载按预期处理应用文件和数据。 |
| Linux | 在记录下来的桌面环境中运行 AppImage。检查 Secret Service、托盘、通知和剪贴板，分别记录 X11 与 Wayland 的结果。 |

## 收发矩阵

- [ ] 在受支持的设备组合上双向配对和发送。覆盖单文件、批量文件、图片、文字、链接、剪贴板、文件夹归档及还原。
- [ ] 分别在同网、跨网、网络切换和 VPN 场景收发。记录实际走直连或中继，按需要单独测试自定义中继认证和发现。
- [ ] 测试配对的同意、拒绝和取消，撤销信任后重新连接，以及收件确认、拒绝、自动接收和取消传输。
- [ ] 检查同名文件、空间不足和保存失败。更换保存目录，尝试打开文件、清除记录并保留文件，以及同时删除记录和文件。
- [ ] 在支持的设备上测试系统分享、拖放、文件和图片剪贴板。
- [ ] Android 测试锁屏、手动接收通知、服务回收、重启解锁和强制停止后重新打开。
- [ ] macOS 测试窗口关闭、空闲睡眠和唤醒。Windows/Linux 测试托盘、登录启动、重复启动和睡眠恢复。

## 升级和发布

- [ ] 从上一个公开版升级。核对本机身份、配对信息、设置、历史和收到的文件。
- [ ] 在配对、传输和文件夹操作期间验证安装门禁。用篡改包核对签名校验，用可控错误确认安装失败后原版本可用。
- [ ] 审阅草稿版本、说明、资源、验收结果和指纹，由维护者确认发布。
- [ ] 发布后打开版本页与下载链接，检查滚动更新源已指向该版本。

## 给用户看的材料

演示应使用真实的候选版本和示例内容。选择能看见发起、接收和结果的片段，并说明设备和网络条件。给出速度数据时同时注明文件大小和测试环境。

更新下载入口、说明与截图时，核对对应版本。测试者遇到的问题要能从安装、配对、收发或升级步骤复现，再决定下一轮优先修什么。 [反馈问题](../CONTRIBUTING.zh-CN.md#反馈问题)
